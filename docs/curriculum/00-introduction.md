# Set Calculus Curriculum

This directory is the canonical Markdown source for the Set Calculus curriculum and future EPUB publication.

The curriculum develops three synchronized disciplines across three levels:

- **Mathematics**: model structure.
- **Logic**: resolve structure.
- **Computer Science**: execute structure.

Simulation economics is the initial shared laboratory.

## Integrated reading path

1. Level I — Relational Hex
2. Differential Equations I — Relational Dynamics
3. Level II — Lattice
4. Differential Equations II — Lattice Dynamics
5. Level III — State Management
6. Differential Equations III — State-System Dynamics

Each level contains Math, Logic, CS, and an economics simulation lab. The same sources can later be compiled into an integrated EPUB or discipline-specific reading paths.
