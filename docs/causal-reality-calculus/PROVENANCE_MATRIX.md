# Causal Reality Calculus Provenance Matrix

This matrix maps each Causal Temporal Economics-derived CRC law to its exact source passage, interpretation level, and calibration status.

## Interpretation levels

- **DIRECT**: the CRC law preserves the source rule with only notation/domain renaming.
- **GENERALIZED**: the source states the rule in an economic or CT-specific domain and CRC lifts it to a broader causal form.
- **INFERRED**: the CRC law is a synthesis of multiple source constraints rather than a single source theorem stated in CRC form.

## Calibration statuses

- **FORMAL-CLOSED**: the source explicitly identifies the formal object/rule as closed.
- **FORMAL-DERIVED**: the CRC rule is mathematically derived from source material, but the source does not assign that exact CRC label.
- **EMPIRICAL-CALIBRATION-PENDING**: numeric/real-world values still require measurement.
- **BRIDGE-REQUIRED**: use across heterogeneous carriers requires a certified bridge.
- **CONDITIONAL-THEOREM**: valid only under stated assumptions.
- **PROVENANCE-REQUIRED**: validity depends on retained evidence/causal lineage.
- **DOMAIN-SCOPED**: the source establishes the rule within Causal Temporal Economics; CRC generalization extends its scope.

## Provenance interpretation rules

### Direct source law

A **DIRECT** row means the source states substantially the same proposition. CRC may normalize notation, but does not add a new causal claim.

### Generalized law

A **GENERALIZED** row means the source establishes the proposition inside Causal Temporal Economics and CRC lifts the same structure into a broader causal domain.

Generalization status must therefore remain visible:

```text
source-supported domain rule
!=
empirically proven universal law
```

### Inferred law

No current Axiom 16-26 is classified solely **INFERRED**. If future CRC synthesis combines multiple passages into a new law that no source states directly, that row must be marked **INFERRED** and list every contributing source passage.

## Calibration discipline

The governing calibration boundary from SRC-CTE-V6-20260909 is:

```text
FORMAL-CLOSED != EMPIRICALLY-CALIBRATED
UNKNOWN != 0
unbridged != commensurable
```

Therefore:

1. formal definition does not imply measured real-world value;
2. missing calibration remains UNKNOWN;
3. cross-carrier arithmetic remains forbidden without a certified bridge;
4. conditional theorems retain their hypotheses;
5. provenance-backed historical claims retain their evidence boundary.
