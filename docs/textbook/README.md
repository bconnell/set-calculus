# Set Calculus Textbook

This workspace will develop the educational presentation of Set Calculus after the dependency map and core vocabulary begin to stabilize.

The textbook should teach the mathematical dependency structure rather than reproduce Calc I / II / III boundaries and rename them.

## Working progression

The current hypothesis is broadly:

```text
state / relationship
-> change
-> accumulation
-> relationships between change and state
-> higher-dimensional structure
```

This is a research hypothesis, not yet the final table of contents. The dependency-map work should determine the actual ordering.

## Compatibility layer

Where appropriate, each chapter should show how the Set Calculus representation maps to conventional notation so a reader with ordinary calculus training can move between the systems.

## Provenance

The published textbook should carry the project's provenance statement and preserve source/derivation information for incorporated material.
