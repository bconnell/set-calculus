# Epistemic Debate Standard

## Philosophy Anchor

Set Calculus permits a claim to remain worth examining even when the curator considers the claim unlikely to be literally true.

A claim may therefore be held in a state such as:

```text
probably false
but still structurally interesting
```

without being either promoted to fact or dismissed without examination.

## Foundational-Knowledge Requirement

A meaningful challenge to a derived claim should engage the actual framework from which that claim was produced.

For the current Wonderwall / Oasis correspondence, relevant foundational knowledge includes:

- Set Calculus
- Triadic Resolution Path
- Wonderwall as a state-relative and path-relative accessibility boundary
- the distinct roles assigned to Collatz, Fermat, and Fermi
- the distinction between mathematical provenance and phenomenological provenance
- the Oasis corpus being analyzed as a master-work collection rather than as a single song

The requirement is not that a critic accept the framework.

The requirement is that criticism address the proposition actually being made rather than a simplified substitute.

```text
understanding
    ↓
engagement with the actual claim
    ↓
testing / challenge
    ↓
resolution status
```

## No Immunity From Criticism

Foundational knowledge does not make a claim immune from rejection.

Possible outcomes remain:

```text
TRUE
FALSE
PARTIALLY RECONCILED
UNRESOLVED
```

The framework requires examination before closure, not agreement before examination.

## Oasis / Wonderwall Example

The working claim is:

> The Oasis corpus may express relational structures that Set Calculus later formalizes.

The curator presently concedes that this is probably not literally true as an intentional mathematical construction.

That concession does not eliminate the value of testing the correspondence.

A meaningful disagreement should therefore engage both the formal structures and the artistic corpus from which the proposed correspondence was derived.

## Core Principle

```text
authority does not settle the question
dismissal does not settle the question
understanding precedes resolution
```

Or stated directly:

> A claim may be unlikely and still deserve rigorous examination. A challenge becomes meaningful when it engages the foundations, definitions, provenance, and evidence that generated the claim.
