# Novelty Classification

## Status

Logical structure / philosophy anchor.

This document records a three-part novelty classification implemented as a **discriminated union** and defined as a **filter type within the logical structures**.

The discriminator identifies the novelty state. The selected branch carries the logical conditions that explain why the object is classified that way.

## Logical Structure Type

```text
DiscriminatedUnion<Novelty> =
    Novel
  | PseudoNovel
  | FauxNovel
```

This is not a plain enum.

A plain enum names one of several states.

A discriminated union selects one branch and preserves the branch-specific structure required to justify that state.

At minimum:

```text
Novelty {
    kind,
    resolution_space_status,
    basis,
    interpretation,
    provenance
}
```

The discriminator is:

```text
kind
```

The remaining values provide the logical basis for the selected branch.

## Novelty as a Filter

Within the logical structures, Novelty acts as a filter over a proposed discovery, interpretation, or formal object.

```text
candidate claim / discovery
        ↓
Novelty Filter
        ↓
inspect resolution-space validity
inspect prior structure / application
inspect interpretation
inspect provenance
        ↓
Novel | PseudoNovel | FauxNovel
```

The filter does not establish truth merely by assigning a label.

It classifies the relationship between the novelty claim and the resolution space in which that claim was produced.

## Branch 1: Novel

```text
Novel {
    resolution_space_status: valid,
    basis: genuinely_new_structure_or_application
}
```

A genuinely new structure, behavior, application, or formal object whose novelty survives examination of the relevant resolution space.

```text
valid resolution space
+ previously absent structure / behavior / application
= Novel
```

Novelty here is not produced merely by changing vocabulary or overlooking prior structure.

## Branch 2: Pseudo-Novel

```text
PseudoNovel {
    resolution_space_status: valid,
    basis: existing_structure_with_new_interpretation
}
```

An existing phenomenon, behavior, or application that receives a materially different structural interpretation, formalization, or framing.

```text
valid underlying object
+ established or previously occurring behavior
+ substantially different interpretation
= PseudoNovel
```

A pseudo-novel result survives correction of the resolution space because the underlying object remains valid.

Example pattern:

```text
existing application
-> different structural interpretation
-> new formal packaging
```

The paradox dual-interface interpretation is currently treated as a candidate pseudo-novel structure: paradox already operates across logic and foundations, while the explicit recursive dual-interface interpretation may be distinctive.

## Branch 3: Faux-Novel

```text
FauxNovel {
    resolution_space_status: invalid,
    basis: apparent_novelty_from_invalid_resolution
}
```

An apparent novelty generated by an incorrect, incomplete, or invalid resolution space.

```text
invalid resolution space
-> apparent new object
-> resolution space corrected
-> apparent novelty collapses
```

A faux-novel object may look new only because relevant structure was omitted, misclassified, improperly constrained, or otherwise resolved incorrectly.

Therefore:

```text
FauxNovel
= novelty artifact produced by invalid resolution
```

## Core Distinction

```text
Novel
= valid space + genuinely new structure

PseudoNovel
= valid space + existing structure + new interpretation

FauxNovel
= invalid space + apparent novelty
```

The decisive filter between pseudo-novel and faux-novel is whether the novelty survives correction of the underlying resolution space.

```text
correct resolution space
        ↓
pseudo-novel survives
faux-novel collapses
```

## Filter Semantics

The Novelty filter can be described as:

```text
N(x, R, P)
```

where:

```text
x = proposed novelty object
R = resolution space in which x was produced
P = prior known structure / application / provenance
```

The filter asks, in order:

```text
1. Is R valid enough to support the novelty claim?

2. If no:
      -> FauxNovel

3. If yes, does P already contain the same structure,
   behavior, or application?

4. If no:
      -> Novel

5. If yes, is the materially new contribution an
   interpretation, formalization, or structural framing?

6. If yes:
      -> PseudoNovel

7. Otherwise:
      -> unresolved classification
```

An unresolved result should remain unresolved rather than being forced into one of the three branches.

## Logical Role

The Novelty Discriminated Union belongs to the family of logical structures because it filters and classifies a proposed discovery relative to:

- the validity of the underlying resolution space;
- prior structure or application;
- the interpretation being proposed;
- provenance;
- later correction or reconciliation.

It is therefore both:

```text
a discriminated union
AND
a logical filter
```

The union defines the possible typed outcomes.

The filter defines the operation that selects among them.

A novelty classification is itself subject to later reconciliation if the relevant resolution space changes.

## Epistemic Status

- Three-part novelty distinction: **asserted conceptual definition**
- Discriminated Union as the structure type: **asserted classification form**
- Novelty as a logical filter: **asserted logical role**
- Paradox dual-interface as pseudo-novel: **working classification, not final novelty determination**
