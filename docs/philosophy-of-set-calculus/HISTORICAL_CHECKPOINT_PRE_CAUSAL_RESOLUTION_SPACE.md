# Historical Checkpoint: Pre-Causal Resolution Space

## Status

Philosophy / provenance anchor.

This checkpoint records the state of the Set Calculus research before causal relations are introduced into the active resolution-space formalization.

It is intended to preserve the order in which the ideas emerged so that later results can be distinguished from concepts added after the fact.

## Current Research Condition

At this checkpoint, the active model is being asked to define **resolution space** without first being given the Causal Relations application layer.

The working expectation is that this should expose the unresolved candidate / witness / path space before causal constraints restrict it.

The present hypothesis is:

```text
pre-causal resolution space
    -> structured unresolved possibility
    -> candidate / witness / path organization
    -> possible relationship to NP
```

The identification with NP is not yet resolved.

It remains possible that the resulting structure instead characterizes P, a larger space containing P and NP behavior, or another object requiring a different mapping.

## Methodological Constraint

Causal relations should not be introduced before the resolution space has been characterized.

The reason is structural:

```text
unresolved resolution space
    ↓
introduce causal relations
    ↓
constrain transitions / accessibility
    ↓
causally filtered resolution space
```

If causal relations are introduced too early, the model is no longer examining the unconstrained resolution space. It is examining a space already filtered by causal admissibility.

This would make it difficult or impossible to determine which structures belonged to the original resolution space and which were consequences of the causal filter.

## Ordering Principle

The current study therefore preserves this order:

```text
1. Define resolution space.
2. Observe its candidate / witness / path structure.
3. Determine what logical structures arise within it.
4. Test its relationship to P, NP, and other complexity objects.
5. Introduce causal relations only after the pre-causal space is independently characterized.
6. Observe what causal relations restrict, transform, or resolve.
```

This ordering is methodological, not yet a theorem.

## Theory as a Logical Structure

This checkpoint also records the current use of **Theory** as a logical structure:

```text
Theory
= structured non-determinative, non-resolved space
```

Theory is not treated as synonymous with ignorance, falsity, or absence of structure.

```text
Theory != Unknown
Theory != False
Theory != Determined
Theory != Resolved
```

A theory space may contain candidate relations, competing structures, possible transforms, unresolved constraints, and provenance without requiring premature closure.

This makes theory a natural logical container for the pre-causal resolution-space study.

## Relationship to P / NP

The working research question at this checkpoint is not assumed to be solved.

Two nearby interpretations remain open:

```text
NP-oriented interpretation:
resolution space describes the larger candidate / witness structure
within which efficiently verifiable solutions may exist.

P-oriented interpretation:
resolution space describes the region directly traversable by an
efficient resolution procedure.
```

The preferred research hypothesis at this checkpoint is that the model is exposing the larger NP-like resolution space, with efficient resolution potentially appearing as a distinguished region or path class inside it.

That preference is recorded as provenance, not as proof.

## Why This Checkpoint Matters

If a later formalization appears to connect Set Calculus to P, NP, P versus NP, or another complexity-theoretic structure, this document preserves that:

- resolution space was being investigated first;
- the possible NP relationship was recognized before causal relations were introduced;
- causal relations were intentionally withheld to avoid prematurely restricting the space;
- the P / NP identification remained explicitly unresolved.

This is meant to prevent later reconstruction from making the discovery path appear cleaner or more deterministic than it actually was.

## Core Principle

```text
Do not constrain the space before you know what space you are constraining.
```

Or in Set Calculus terms:

```text
define unresolved structure
    before
applying a transform that restricts admissible resolution
```

## Epistemic Status

- Pre-causal ordering requirement: **asserted methodological principle**
- Theory as non-determinative / non-resolved logical structure: **asserted conceptual definition**
- Resolution-space relationship to NP: **hypothesized**
- Resolution-space relationship to P: **open alternative**
- Any claim about P vs NP itself: **unresolved**
